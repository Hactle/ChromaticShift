# 🎮 Chromatic Shift

A minimalist 2D platformer built around color-based player states.

Chromatic Shift focuses on clean visuals and core gameplay mechanics. The player controls a white cube and must reach the end of each level by switching between color states, each of which changes how the character moves and interacts with the environment. The game intentionally uses a monochrome visual style — gray platforms and a muted background — to keep attention on mechanics and level design rather than graphics.

---

## 🕹 Gameplay

The core mechanic of the game is **color shifting**.  
At any moment, the player can change their color state to gain specific abilities required to overcome obstacles and traverse the level.

Each level is designed around combining and mastering these states.

---

## 🎨 Color States

- 🔵 **Blue**
  - Higher jump
  - No sliding on ice surfaces

- 🔴 **Red**
  - Increased movement speed
  - Dash ability

- 🟢 **Green**
  - Wall climbing on vine-covered surfaces

---

## 🗺 Levels

- Tutorial level introducing the core mechanics
- 2 main levels focused on combining color abilities

---

## 🎨 Visual Style

- White cube player character
- Single-texture gray platforms
- Monochrome background
- Minimalist, high-contrast design

The visual simplicity is intentional and supports readability and precise platforming.
